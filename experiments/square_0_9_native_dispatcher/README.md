# Square 0..9 - BolgeForge-native runtime dispatcher

Status: **EXPERIMENTAL, DEMONSTRATED for ten single-digit vectors** under
`mb_ref` and the independent strict loader. It is not a certified core artifact
and does not make a historical or novelty claim.

This directory records a BolgeForge-native `square(0..9)` program generated by
`build_native_square.py`. It does not use the LMAO source or LMAO output. The
companion `experiments/square_0_9_lmao_oracle/` remains the independent oracle
record.

## Architecture

The input digit is read by `/` at cell 0. The bootstrap uses `C=85` and seven
rotations:

```text
/ j j j j p (j*)^7 j i
```

Initial cells:

```text
mem[40]=77  mem[78]=84  mem[85]=48
mem[49]=85  mem[50]=48  mem[51]=83  mem[84]=49
```

The dispatcher computes:

```text
T_d = op(48 + d, 85)
S_d = rot^7(T_d)
Q_d = op(S_d, 48)
```

For digits `0..9`:

```text
S = [28471, 28444, 28498, 28633, 28606, 28660, 28795, 28768, 28822, 28714]
Q = [1071, 1098, 1125, 990, 1017, 1044, 747, 774, 801, 828]
```

The branch at `S_d+1` is `p j j i`:

- `p` reads `mem[50]=48` and writes `Q_d` to cell 50.
- `j` follows `mem[51]=83`.
- `j` follows `mem[84]=49`.
- `i` reads `mem[50]=Q_d` and jumps to `Q_d+1`.

The arena starts at `Q_d+1`. It applies `k` rotations with `(j j *)`, then
`j j j` leaves `d=B=rot^k(Q_d)+1`, where `B` is the per-digit data base. The
per-digit recipe follows immediately and is encoded as `p`/`*`/`<` groups
ending in `v`. The recipe reads its data from `B`, so each digit gets a separate
data block.

The selected data ranges are disjoint and avoid the bootstrap, branch blocks,
and `Q_d+1..Q_d+26` arena blocks. The builder searches the layout and verifies
every source cell against the strict instruction set at its load address.

## Verified behavior

```text
input  output  status
0      0       HALT
1      1       HALT
2      4       HALT
3      9       HALT
4      16      HALT
5      25      HALT
6      36      HALT
7      49      HALT
8      64      HALT
9      81      HALT
```

Both `mb_ref` and the strict Python loader produce the same output for all ten
inputs. The strict runs halt in 39-48 instructions. The artifact is single-digit
only; multi-digit input is outside this experiment.

## Reproduce

```bash
cd "$(git rev-parse --show-toplevel)"
python3 experiments/square_0_9_native_dispatcher/build_native_square.py
python3 experiments/square_0_9_native_dispatcher/verify_native_square.py
```

`build_native_square.py` regenerates `native_square.mal`, checks the ten
`mb_ref` vectors and the ten strict-loader vectors, and prints the selected
layout plus the artifact SHA-256. The committed artifact must reproduce SHA-256
`6026ddc03133c824d821dcc5b779fce414fd07c2e3d3c8591b8bcaadcbcfd6d0`.

## Limits

- Single decimal digit `0..9` only.
- Finite vectors; no universal proof for other inputs.
- The ten `mb_ref` and strict-loader runs are the entire runtime evidence here.
- The old source-table dispatcher remains exhausted; this experiment uses the
  runtime dispatcher instead.
- No product, no general arithmetic, and no LMAO-derived source in this
  directory. GPL/provenance questions from the LMAO oracle do not apply to this
  builder output because it is generated from `constants.py`. The blocked
  product extension is documented in
  `docs/evidence/2026-10-22-product-0-9-negative/`.
- No commit or certification is implied by this directory.
